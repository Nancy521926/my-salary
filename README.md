# My salary · Android 工资条生成器

A tiny offline Android app that turns salary records into a high-resolution table image (or PDF) styled like a paper payslip. Pure HTML/CSS/JS in a WebView shell, no third-party libraries, no network access.

一个离线的安卓工资条生成器：把工资数据填进去，一键把整张表画成高清图片存进相册（也可以走系统打印另存为 PDF）。25 列、表头两行、细黑边框，按纸质工资条样式还原。

---

## 一、安装

安装包：`output/MySalary-v1.1.apk`（约 57 KB）

1. 把 APK 传到手机（微信文件传输助手 / 数据线 / U 盘都行）。
2. 在手机上点开安装。首次会提示「未知来源应用」，按系统提示允许安装即可。
3. 安装后桌面出现蓝色 ¥ 图标的「My salary」。

| 项 | 值 |
|----|-----|
| 包名 | `com.yili.payslip` |
| 版本 | 1.1（versionCode 2） |
| 系统要求 | Android 7.0（API 24）及以上 |
| 权限 | 仅 Android 9 及以下需要「存储」权限，用于写入相册 |
| 联网 | **完全不联网**，数据只存在手机本地 |

## 二、界面说明

打开后从上到下：

- **顶栏** —— 右侧「载入示例」按钮，点一下填入一条虚构示例记录（张三 / 2026-09 / 底薪）。
- **工资条记录** —— 每条一张卡片，显示姓名和实发金额。点「编辑」进编辑页，点「删除」移除。右上角「自动计算」开关控制是否按公式自动算。
- **新增一条工资条** —— 新建空白记录并直接打开编辑页。
- **打印预览** —— 和保存出来的图片 1:1 一致，横向滑动可看全部 25 列。
- **底部两个按钮** —— 保存到相册 / 打印·存 PDF。

## 三、填数据

点「新增一条工资条」或某条记录的「编辑」，弹出编辑页，按分组填写：

| 分组 | 字段 |
|------|------|
| 基本信息 | 序号、月份、姓名、薪资类别 |
| 出勤 | 实勤小时数、缺勤小时 |
| 固定项 | 底薪、全勤奖、夜班补贴、其它、住房补贴 |
| 加班 | 平时加班小时 / 加班费、假日加班小时 / 加班费、法定加班小时 / 加班费 |
| 扣减 | 扣款、代扣社保、社保补缴、个人所得税、其它扣款 |
| 其它 | 备注 |

### 自动计算规则

打开「自动计算」后，改了底薪或加班小时数，下面这些会自动重算：

```
时薪        = 底薪 ÷ 174                 （21.75 天 × 8 小时）
平时加班费  = 时薪 × 1.5 × 平时加班小时
假日加班费  = 时薪 × 2   × 假日加班小时
法定假加班费= 时薪 × 3   × 法定加班小时
应发合计    = 底薪 + 全勤奖 + 三档加班费 + 夜班补贴 + 其它 + 住房补贴 − 扣款
实发        = 应发合计 − 代扣社保 − 社保补缴 − 个人所得税 − 其它扣款
```

**手动改过的格子不会被覆盖。** 某个应发合计和公式对不上（单位口径不同）时，直接手填数字，该格就转为手动值，之后再改其它字段也不会被重算掉。

## 四、导出

### 保存到相册（主用法）

点「保存到相册」，App 会把整张表按 **200 DPI** 直接画成 PNG：

```
相册 → 工资条 → 工资条_20261103_1430.png
```

- 表头约 97px 高，每人一行约 60px，表宽 2307px；一张 20 人的表约 0.4 MB。
- 图里只有表格本身，四周留白，白底黑框，直接发微信、发钉钉都清楚。
- 人多时会自动降低 DPI（画布高度上限 10000px），保证不爆内存。
- Android 10 及以上：写 `Pictures/工资条`，相册里自动出现「工资条」文件夹；
  Android 9 及以下：写 `Pictures/工资条` 并广播媒体扫描，相册同样能看到。

### 打印 / 存 PDF

点「打印 / 存 PDF」调起系统打印服务，A4 横向，**只打印表格本身**（不会带上 App 的按钮和卡片）。打印对话框里选「另存为 PDF」就能导出一份 PDF 文件。

## 五、表格结构

25 列，顺序固定：

```
序号 | 月份 | 姓名 | 薪资类别 | 实勤小时数 | 底薪 | 全勤奖 |
平时加班小时 | 平时加班费 | 假日加班小时 | 假日加班费 | 法定加班小时 | 法定假加班费 |
夜班补贴 | 其它 | 住房补贴 | 缺勤小时 | 扣款 | 应发合计 |
代扣社保 | 社保补缴 | 个人所得税 | 其它 | 实发 | 备注
```

表头换行按原表样式：`实勤小/时数`、`平时加/班小时`、`平时加班/费`、`假日加/班小时`、`假日加班/费`、`法定加/班小时`、`法定假/加班费`、`住房补/贴`、`缺勤小/时`、`个人所得/税`。

多人使用：新增多条记录，图片里每人一行，表头只在最上方出现一次。

---

## 六、已知差异

金额列一律两位小数（例如 `10` 画成 `10.00`），保持视觉统一。

## 七、开发与重新构建

```
my-salary/
  web/index.html          ← 全部界面 + Canvas 画表逻辑（纯 JS，无第三方库）
  android/                ← 原生外壳（单 Activity + WebView + JS 桥）
  tools/build.py          ← 无 Gradle 的构建脚本（aapt2/javac/d8/zipalign/apksigner）
  tests/serve.py          ← 本地调试服务
  output/MySalary-v1.1.apk  ← 产物
```

需要 **JDK 17** 和 **Android SDK**（build-tools 34.0.0 + 任一 platform，脚本会自动挑版本）：

```bash
export JAVA_HOME=/path/to/jdk-17
export ANDROID_SDK=/path/to/Android/sdk
python3 tools/build.py
```

脚本依次执行 `aapt2 compile → aapt2 link → javac → d8 → 打包 classes.dex → zipalign → apksigner 签名并校验`，产物覆盖 `output/MySalary-v1.1.apk`。

> 构建全程复制到纯 ASCII 的临时目录里进行 —— aapt2 不认含中文的路径参数，所以先复制再编译。

本地调试：

```bash
python3 tests/serve.py      # 浏览器打开 http://127.0.0.1:8765
```

浏览器控制台里可以直接调 `__payslip.drawTableCanvas(records)` 拿到画布，`__payslip.pickDpi(records)` 看当前 DPI。

## 八、注意事项

- 本 App 是**离线**的，不采集、不上传任何数据；所有记录存在手机本地存储里，卸载 App 会一并清除。
- 保存的 PNG 是标准图片，任何相册、微信、打印店都能直接打开打印。
- 换手机 / 重装前，记得先把相册里的图片拷出来备份。
